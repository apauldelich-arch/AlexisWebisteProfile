# Alexis Paul Delich - Professional Profile Website

This repository contains the source code for my professional profile and portfolio website.

## Tech Stack
- HTML5
- CSS3 (Variables, Flexbox, Grid, Animations)
- Vanilla JavaScript (Canvas particles, Scroll effects)

## Structure
- Single-page application approach.
- Responsive design tailored for mobile and desktop.
- Engaging UI with micro-interactions and scroll-revealing elements.

## Deployment
This project is set up to be easily deployed on standard platforms like [Vercel](https://vercel.com/) or GitHub Pages.
